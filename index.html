Evaluation boundary: Lexical matching can miss paraphrases; coverage is a heuristic rather than calibrated uncertainty. Exact quotation prevents invented wording but does not establish truth, relevance or safety of the underlying source. A malicious instruction may still appear in a retrieved quote, but the program never executes it. The API rebuilds the index per request and is intended for small local corpora.
